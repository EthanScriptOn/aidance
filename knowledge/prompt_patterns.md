# Prompt Patterns

## Fast Behavioral Coverage

Use for:

- protest
- scolding
- intimidation
- being excluded
- being forced into a role
- short emotional turn

Default:

```text
Duration: 6s
Shot count: 7
```

Structure:

```text
Shot 1, side medium-wide, 0.8s:
Establish who has power and who is outside it.

Shot 2, close-up, 0.7s:
The pressured character shows the first reaction.

Shot 3, medium close-up, 0.7s:
Authority blocks, teases, commands, or redirects.

Shot 4, extreme expression close-up, 0.6s:
The pressured character still resists or hesitates.

Shot 5, action close-up, 0.8s:
The pressure becomes physical or concrete.

Shot 6, reaction close-up, 0.9s:
The pressured character changes state.

Shot 7, group or relationship landing, 1.5s:
The new role or relationship becomes clear.
```

## Insert + Reaction

Use for:

- suspicious object
- clue
- phone message
- rope tension
- hand tightening

Structure:

```text
Shot 1: object or action insert
Shot 2: eyes / face reaction
Shot 3: hand or posture tries to hide the reaction
```

## Reveal + Reaction

Use for:

- seeing a monster
- discovering a hidden space
- looking back after a sound

Structure:

```text
Shot 1: setup space, no reveal yet
Shot 2: body turns toward source
Shot 3: delayed reveal
Shot 4: reaction or relationship landing
```

## Mechanism Action

Use for:

- climbing down
- pulling rope
- tying rope
- falling
- grabbing an object

Structure:

```text
Shot 1: start relation and mechanism
Shot 2: hand / foot / object close-up
Shot 3: body weight changes
Shot 4: result state
```

## Prompt Rules

- If the beat is human conflict, start with Fast Behavioral Coverage.
- If the beat is object information, start with Insert + Reaction.
- If the beat is threat confirmation, start with Reveal + Reaction.
- If the beat is physical cause-and-effect, start with Mechanism Action.
