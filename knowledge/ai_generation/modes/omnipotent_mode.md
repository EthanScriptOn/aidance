# 全能模式手册

> 适用范围：多图参考 + 文本 prompt 的图生视频/文图混合生成。常见输入为人物图、场景图、道具图。
> 不适用：已经生成好的成品分镜图动态化；那属于 `storyboard_frame_mode.md`。

---

## 一、适用场景

- 已有场景图、人物图、道具图。
- 目标是把角色放进环境中，并保持身份、服装、道具一致。
- 动作较小：站位、看向、持物、轻微移动、简单 reaction。
- 需要快速试镜头感觉，而不是强动作表演。

---

## 二、优势与风险

优势：

- 素材组合灵活。
- 人物、场景、道具可以分别锚定。
- 适合角色一致性和空间搭建。

风险：

- 人物和场景都被锁得太死，动作弱。
- 多图身份容易混。
- 如果只写“延续上一拍”，模型不知道上一条视频是什么。
- 关键物不 `@` 时容易被替换或丢失。

---

## 三、上传与引用规则

默认上传顺序：

1. 主角色
2. 主场景
3. 关键道具 / 武器 / 状态变体
4. 其他补充角色或道具

正文必须明确：

- 谁是主动作主体。
- 哪张图锁人物身份。
- 哪张图锁场景空间。
- 哪张图锁关键叙事物。
- 当前画面的站位事实，而不是“延续上一拍”。

关键物规则：

- 只要“这个物不出现，戏就不成立”，该物必须单独上传并在正文中 `对象名@图片X`。
- 人物、场景、关键物承担不同信息职责时，三者都要明确引用。
- 高风控敏感物可在正文中改写为“关键旧物 / 身份指向物 / 异常遗落物”，但上传顺序和 registry 仍要保持可追踪。

---

## 四、适合的 prompt 结构

```text
使用 @图片1 锁定 [人物身份]，@图片2 锁定 [场景空间]，@图片3 锁定 [关键道具]。
当前画面：[谁在左/右/前/后]，[谁持有什么]，[谁看向哪里]。
动作：[主体] 做 [具体动作]，导致 [道具/站位/情绪结果]。
镜头：[景别/机位/是否静镜或轻微移动]。
禁止：[不要混用身份，不要丢失关键物，不要翻转左右关系]。
```

---

## 五、何时切换策略

切换到行为起始帧：

- 人物连续不动。
- 只有镜头在动。
- 角色设定图 + 场景图把动作锁死。

切换到首尾帧：

- 起始构图和结束构图非常明确。
- 需要保证姿态、距离或构图落点。

切换到分镜图模式：

- 复杂群像站位容易漂移。
- setup/reveal 区必须强分离。
- 需要稳定落成 2 到 4 个关键节点。

---

## 六、常见失败与修正

| 失败现象 | 修正 |
|---------|------|
| 关键物丢失或变成普通物 | 单独上传关键物，正文 `对象名@图片X` |
| 人物身份混淆 | 明确“@图片X 是谁，只锁什么” |
| 只轻推、人物不动 | 改行为起始帧或双镜头 |
| 连续性乱 | 写当前站位事实，不写“延续上一拍” |
| 正面摆拍 | 改偏侧关系镜、后侧三分之四或 insert -> reaction |
