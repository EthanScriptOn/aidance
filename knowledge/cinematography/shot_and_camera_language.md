# 摄影语言手册

> 专业归属：摄影指导 / 分镜导演。
> 用途：统一景别、机位、构图、画面地理关系与运镜选择。这里解决“镜头怎么看、相机怎么动”，不解决镜头之间怎么剪，也不解决 AI 模型如何上传素材。

---

## 一、摄影判断顺序

1. 先判断镜头叙事任务：交代空间、交代动作、交代情绪、制造压迫、揭示威胁。
2. 再选景别：空间关系用远景/全景，动作链用全景/中景，情绪变化用中近景/近景，局部信息用特写。
3. 再选观看立场：平视、俯拍、仰拍、后侧三分之四、侧面、背面、过肩、主观。
4. 再选构图：人物位置、负空间、前中后景、对角线、中心或边缘。
5. 最后选一个主运镜；一个镜头优先只承担一种主运镜。

原则：

- 恐怖/悬疑里，静镜往往比乱动更有压迫感。
- 交代压迫优先用边缘构图、负空间和镜头距离变化，不要只靠“慢慢推近”。
- 如果单镜头怎么写都只变成“轻推”，优先改成双镜头、首尾帧或更明确的动作起始帧。
- 多人全身镜只能作为关系建立工具，不能成为所有 Beat 的默认答案。只要叙事任务进入情绪、判断、受力、犹豫、压迫或恐惧，就必须主动切到更具体的脸、手、肩背、侧脸、主观或插入镜头。
- 每个 Beat 在确定景别前，必须先写清 `emotional_camera_reason`：当前景别、机位、构图或运镜到底在表达谁的哪一种内心状态 / 权力关系 / 生理受力。

## 二、景别库

| 景别 | 英文常用名 | 观看效果 | 最适合 | 不适合 |
|------|-----------|---------|-------|-------|
| 极远景 | extreme wide shot / EWS | 人物极小，空间压过人 | 建立环境、孤立感、命运感 | 表情镜头 |
| 远景 | wide shot / WS | 人物完整可见，空间关系清楚 | 出入场、追逐起点、多人调度 | 微表情 |
| 全景 | full shot / FS | 人物全身完整，动作清晰 | 站位、行走、动作起手 | 细腻面部戏 |
| 中远景 | medium long shot / MLS | 膝上到头，兼顾动作与关系 | 警觉、观察、对峙 | 极细表情 |
| 中景 | medium shot / MS | 腰上到头，动作和情绪平衡 | 说话、持物、探身、回头 | 大空间交代 |
| 中近景 | medium close-up / MCU | 胸上到头，脸开始成为重点 | 紧张、压抑、观察、惊觉 | 大幅身体动作 |
| 近景 | close-up / CU | 面部成为主体 | 紧张、惊惧、决断、听觉反应 | 空间交代 |
| 极近特写 | extreme close-up / ECU | 单一局部强烈放大 | 眼睛、手指、伤痕、道具母题 | 长时间持续使用 |

## 三、机位与观看立场

| 机位/构图 | 英文常用名 | 心理效果 | 适用场景 | AI 视频提示写法建议 |
|----------|-----------|---------|---------|------------------|
| 平视 | eye level | 正常、纪实、观众默认感知 | 常规叙事、人物观察 | `平视中景，正常观察视角` |
| 轻俯角 | high angle | 人物弱、小、被压住 | 害怕、蹲守、无助 | `轻微俯拍，人物显得更弱` |
| 高俯角 | bird's-eye / overhead | 命运感、空间棋盘感 | 洞口、土丘、被困 | `高角度俯视，人物被空间吞没` |
| 轻仰角 | low angle | 人物有压迫、威胁增强 | 发号施令、起身逼近 | `轻微仰拍，加强压迫感` |
| 贴地仰角 | worm's-eye | 异常、怪物、威胁占据画面 | 血尸、踩踏、坠地后视角 | `贴地仰拍，从地面看上去` |
| 后侧三分之四 | rear three-quarter | 跟随人物观察，兼顾脸和前方空间 | 看洞口、看门缝、盯远处 | `后侧三分之四机位，能看到侧脸与前方空间` |
| 侧面机位 | profile / side angle | 姿态和表情轮廓清楚 | 说话、屏息、倾听 | `偏侧面机位，侧脸清晰可见` |
| 正背面 | back shot | 匿名、疏离、孤独 | 远眺、等待、被环境吞没 | `从背后观察人物与前方空间关系` |
| 过肩 | OTS | 双人关系明确，带主观立场 | 对话、对视、窥视 | 仅在模型能稳定处理前景遮挡时使用 |
| 主观镜头 | POV | 代入角色感知 | 看洞内、奔跑、弥留 | `主观视角，看到角色眼前所见` |

## 四、构图与空间关系

| 构图方法 | 效果 | 最适合 | 提示写法建议 |
|---------|------|-------|------------|
| 三分法居左/居右 | 画面更有方向感 | 人物看向未知、留出危险空间 | `人物位于画面左侧，右侧留出黑暗空间` |
| 负空间 | 让空白/黑暗成为威胁来源 | 洞口、门口、树林深处 | `大面积黑暗留白压住画面` |
| 前中后景分层 | 让空间更有深度 | 洞口、道具、林地 | `绳索为前景，人物在中景，洞口在背景` |
| 对角线构图 | 增强动势和不稳定感 | 跑动、倾斜、危险临近 | `身体与洞口边缘形成斜向动势` |
| 中心构图 | 仪式、压迫、被凝视 | 怪物正面、揭示时刻 | `人物正对镜头居中，压迫感很强` |
| 边缘构图 | 不安全、被世界挤压 | 恐惧、偷看、躲藏 | `人物贴近画面边缘，显得不安全` |

## 五、运镜库

| 运镜 | 英文常用名 | 心理效果 | 适用场景 | 不适合 | AI 视频写法建议 |
|------|-----------|---------|---------|-------|----------------|
| 静镜 | locked off / static shot | 等待、压迫、不可逃脱 | 洞口守候、听动静、揭示前停顿 | 想靠镜头本身制造大变化 | `镜头保持不动` |
| 推镜头 | dolly in | 情绪聚焦、揭示关键、压迫靠近 | 情绪爆发、发现异常、关键揭示 | 人物静止且空间层次少时易变成放大 | `镜头缓慢向前推近` |
| 极慢推近 | slow dolly in | 情绪逐步压紧 | 怀疑、意识到危险、沉默压迫 | 场景层次少、人物太静 | `极缓慢推近一点点` |
| 拉镜头 | dolly out | 留白、抽离、显出人物渺小 | 结尾、余韵、揭示更大环境 | 高强度即时反应 | `镜头稳定向后拉远，逐渐带出环境` |
| 摇镜头 | pan | 扫视、连贯交代、替代剪切 | 环境介绍、多人同框、秘密搜索 | 强情绪贴脸 | `镜头水平缓慢摇动，依次扫过环境或人物` |
| 横向滑移 | lateral move / track | 产生视差，像窥视或观察 | 洞口边、门外、林间、隔着前景观察 | 大幅情绪特写 | `沿洞口边缘轻微横向移动` |
| 升镜头 | crane up / pedestal up | 抽离、宏观、命运感 | 开场、揭示环境、离开人物 | 小空间强情绪 | `镜头从低处平稳升高，逐渐带出更大空间` |
| 降镜头 | crane down / pedestal down | 压向危险、落向细节 | 洞口、揭示地面/道具 | 复杂人物动作戏 | `镜头从高处缓慢下降，落向主体或危险区域` |
| 小弧线移动 | subtle arc / orbit | 关系变化、立场变化 | 对峙、绕着对象观察 | 复杂多人物 | `轻微弧线移动，幅度很小` |
| 环绕镜头 | orbital shot / orbit | 登场、仪式感、展示主体 | 角色登场、关键物展示 | 易把多人物空间转乱 | `镜头围绕主体平稳环绕，幅度控制在 90 到 180 度内` |
| 跟拍 | tracking shot | 跟随动作，增强参与感 | 奔跑、追逐、急行 | 原地静态情绪戏 | `镜头跟随人物移动` |
| 手持 | handheld | 紧张、失控、呼吸感 | 逃命、搏斗、主观慌乱 | 需要克制与庄重 | `轻微手持晃动` |
| 先静后动 | hold then move | 先压住再推进 | 悬疑、发现异常、呼吸停顿 | 极短镜头 | `先保持静止片刻，再轻微移动` |

按情绪选运镜：

| 情绪 | 首选 | 备选 | 说明 |
|------|------|------|-----|
| 悬疑等待 | 静镜 | 先静后动 | 让观众自己等待 |
| 宏大开场 | 升镜头 / 降镜头 | 拉远揭示 | 先给世界，再给人物 |
| 偷看 / 观察 | 横向滑移 | 后侧轻压低 | 更像“人屏住呼吸在看” |
| 紧张加重 | 极慢推近 | 双镜头推进 | 单镜头太死时直接切镜头 |
| 惊吓揭示 | 静镜 + 硬切 | 突然近景 | 不依赖花哨运镜 |
| 场景扫描 / 群像交代 | 摇镜头 | 拉远揭示 | 用连贯扫视代替过多切镜 |
| 逃命 / 搏斗 | 跟拍 / 手持 | 快切 | 让身体和空间都失稳 |
| 角色登场 / 仪式感 | 环绕镜头 | 低角度推近 | 适合英雄、反派、关键物件出场 |
| 庄严 / 悲剧 | 静镜 | 轻微拉远 | 克制比炫技更有力 |

## 六、常用摄影模板

### 1. 观察类

- 景别：MLS / MS / MCU
- 机位：后侧三分之四 / 偏侧面
- 构图：人物偏一侧 + 前方负空间
- 写法：`洞口外侧后侧三分之四中景，人物蹲在左侧，右侧保留洞口黑暗空间`

### 2. 压迫类

- 景别：MS -> MCU
- 机位：轻俯角 / 轻仰角 / 更低更近的二镜头
- 构图：黑暗面积逐步增加
- 写法：`第一镜建立人物和洞口关系，第二镜更近更低，洞口黑暗占更多画面`

### 3. 情绪类

- 景别：MCU / CU
- 机位：偏侧面 / 正侧面
- 构图：面部为主，背景简化
- 写法：`中近景偏侧面，清楚看到侧脸眉眼和嘴部变化`

### 4. 动作类

- 景别：FS / MLS / MS
- 机位：平视 / 轻低角
- 构图：保留身体主要动作链
- 写法：`中景平拍，完整看见持枪、后坐、压枪和目标受击反应`

## 七、影视化技法调度

> 用途：防止漫剧镜头长期退化成“多人全身站位说明图”。技法调度不是炫技，而是让观众通过镜头距离、角度、遮挡、运动和光线读到人物心理。

### 1. Beat 观看关系分类

每个 Beat 先判断观众应该处在什么观看关系中，再选择景别和机位：

| 观看关系 | 核心问题 | 首选镜头 |
|---------|---------|---------|
| 空间事实 | 谁在哪，危险入口在哪 | 全景 / 中全景 / 高俯角 |
| 动作机制 | 身体怎么完成动作，力从哪来 | 中景 / 侧面 / 局部 insert / 机制剖面 |
| 内心状态 | 角色怎么被压住、动摇或决断 | 中近景 / 近景 / 侧脸 / 眼手特写 |
| 权力压迫 | 谁压住谁，谁无法反抗 | 轻仰 / 轻俯 / 过肩 / 负空间压迫 |
| 主观感知 | 角色看见、听见或误判了什么 | POV / 后侧三分之四 / 视线推进 |
| 反应落点 | 事件造成了什么心理后果 | reaction close-up / hand insert / 肩背停顿 |
| 机制揭示 | 观众必须理解复杂空间结构 | 侧剖面 / cutaway / 高俯角 + 局部动作 |

### 2. 多人全身镜限制

- `多人全景 / 全身群像` 的默认功能只有两个：建立空间关系，或展示大幅身体调度。
- 一个 Beat 如果包含 2 个以上镜头，第一镜可以是 master，但后续至少有一镜必须改变观看关系：收脸、收手、收侧脸、转 POV、插入关键物、或切机制镜。
- 情绪 Beat 禁止从头到尾都用多人全身。若必须保持群像连续性，也要通过前景绳线、手部、侧脸、肩背或局部光斑让内心状态可读。
- 如果最终 prompt 中所有角色都“全身可见 + 站在洞口 + 轻微动作”，视为未完成影视化调度。

### 3. 内心状态技法菜单

| 内心 / 关系 | 可选技法 | Prompt 落地重点 |
|------------|---------|----------------|
| 被命令压住 | 轻俯角压人 / 近景侧脸 / 过肩压迫 | 目光被迫避开、下颌不动、肩线僵住 |
| 想动但不能动 | 脚部 insert / 手指攥紧 / 侧脸停顿 | 脚不迈、身体前倾、手部替代行动 |
| 恐惧但强撑 | 中近景偏侧 / 负空间压脸 / 冷边缘光 | 眼部小高光、呼吸收短、嘴角压住 |
| 权威下令 | 轻仰中景 / 手部道具 insert / 队列反应 | 道具像指挥棒，其他人异步被压回 |
| 空间吞人 | 高俯角 / 侧剖面 / 洞口负光 | 人物被黑暗遮掉局部，只留边缘光 |
| 失控受力 | 手持轻晃 / 低角 / 绳线 insert | 受力方向、脚步打滑、身体反向拉扯 |

### 4. 复杂空间机制镜

竖井、下水道、洞口、狭窄通道等动作若观众看不懂空间结构，必须补机制镜：

- `高俯角机制镜`：看清洞口、绳线、地面守位和队列。
- `侧向机制镜`：看清身体沿竖井边缘下降、脚找支点、手抓绳受力。
- `侧剖面 / cutaway`：当洞口太黑或入口动作反复失败时，用非写实剖面式镜头交代垂直深度与人物上下关系。
- 机制镜服务“动作可信”，不服务展示人物全貌；洞内若设定为纯黑，剖面也只显示边缘轮廓、绳线张力和身体剪影。

## 八、AI 漫剧摄影注意事项

- 场景九宫格/十六宫格适合做“镜头母版”，不等于最终视频参考图。
- 如果镜头重点在表情，不要只给后背或太远的后侧机位。
- 如果模型容易误判前景遮挡为第二个人，避免 dirty OTS，改用 clean 后侧机位。
- 运镜语句优先放在 prompt 前半段，权重更高。
- 只保留一个主运镜词，不同时写“推近、压低、绕拍、进入洞内”。
- 如果镜头总是死，优先减少运镜描述、改用双镜头或行为起始帧，而不是继续叠加镜头术语。

## 九、连续性与画面地理关系

同一场景连续 Beat，默认先保住 **screen geography**，再谈镜头变化。

`screen geography` 至少包含：

- 谁在画面左 / 右
- 谁更靠前 / 更靠后
- 谁更高 / 更低
- 谁压住谁

对连续群像戏，最好把以上信息压缩成可直接复用的固定屏幕站位事实。不要只写“延续上一拍”，而要写成当前镜头能直接执行的 blocking：

- `老烟头位于画面中央偏右略高位，老二在左前侧顶上来，大胡子在老二侧后，老三缩在外围低位。`
- `镜头仍停留在同一轴线这一侧，不越轴，不翻转左右关系。`
- `人物不换位，镜头只从 master 收到冲突核心。`

反例：

- `四个人围在一起。`
- `切到更近的争执镜头。`
- `老二和老烟头对峙。`
