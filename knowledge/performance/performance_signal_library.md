# 表演信号库

> 用途：把“紧张、惊恐、压抑、怀疑、决绝”这类抽象情绪，翻译成模型更容易执行的可见信号。
> 原则：禁止只写情绪标签，必须写观众能看到的脸部、呼吸、姿态、手部和重心变化。

---

## 一、表演写法总原则

- 先写主状态，再写 2~3 个可见信号。
- 不要只写“很紧张”“很害怕”，要写脸和身体怎么体现。
- 表情和身体必须连在一起，避免“脸在演，身体像木头”。
- 微动作要“看得见”，不能全写成极弱到模型忽略的信号。

推荐结构：

`基础姿态 + 呼吸/受力 + 脸部信号 + 手部/下肢补充`

---

## 一-2、表演变化轨迹与群像规则

- 不要只给模型一个静态表情标签，要写**变化轨迹**。
- 推荐写成：`起点状态 -> 触发点 -> 可见微变化 -> 再压住 / 不爆开`
- 同一句台词或同一个异常信号，不要让所有配角同步做出一模一样的反应。
- 群像镜头里，主角色可以拿到完整变化链；配角每人只给 1~2 个微反应，且触发点略有先后。
- 配角反应要“短、准、可见”，不要把每个人都写成一整段大表演，否则模型会平均化、群像会发木。

推荐结构：

`原状态 + 听到/看到的触发 + 一下可见变化 + 又压住`

示例：

- `大胡子先只是压着眉头盯地，听到“血尸”后下颌明显收紧一下，鼻翼轻微张开，眼神短暂抬起又压回去，嘴唇有一次很轻的抿紧。`
- `老二原本还顶着一股不服的劲，听到关键判断后眼神先是一顿，嘴角僵一下，胸口起伏短暂停半拍，随后又重新压住。`
- `老三原本带一点少年赌气，听到这句话后嘴角慢慢收住，眼睛不自觉睁大一点，又很快压回去，身体不敢乱动，只剩很轻的呼吸起伏。`

反例：

- `大胡子表情紧张。`
- `老二下颌收紧，眼神压在地上。`
- `所有人都很震惊地看着洞口。`

## 二、脸部信号词典

| 部位 | 可见信号写法 | 适合情绪 |
|------|-------------|---------|
| 眉 | 眉头轻微收紧 / 眉心压住 / 眉峰短暂抬起 | 紧张 / 怀疑 / 惊觉 |
| 眼 | 眼睑绷住 / 眼睛微微睁大 / 视线固定不散 / 眨眼突然变少 | 紧张 / 惊恐 / 专注 |
| 眼神 | 眼神死死盯住 / 视线快速确认 / 目光短暂停住 | 紧张 / 着急 / 发现异常 |
| 嘴 | 嘴唇压紧 / 嘴角发僵 / 嘴微微张开又压住 | 压抑 / 惊恐 / 想说又不敢说 |
| 下颌 | 下颌发硬 / 咬紧 / 短暂绷住 | 紧张 / 决绝 / 压住情绪 |
| 面部整体 | 侧脸绷住 / 面部肌肉短暂停滞 / 从平静转为警觉 | 观察 / 惊觉 / 压迫 |

## 三、身体信号词典

| 身体层 | 可见信号写法 | 适合情绪 |
|-------|-------------|---------|
| 呼吸 | 呼吸让肩背明显起伏 / 呼吸短促但被压住 / 胸口起伏变快 | 紧张 / 惊恐 / 着急 |
| 肩背 | 肩膀微微发紧 / 背部轻微绷住 / 肩膀短暂停顿 | 警觉 / 压力 / 惊觉 |
| 手指 | 手指缓慢收紧 / 指节发白 / 手掌更用力按住地面 | 紧张 / 决断 / 压住自己 |
| 手臂 | 手臂因为紧张轻微发颤 / 压枪稳定 / 伸手试探后停住 | 紧张 / 动作准备 / 试探 |
| 重心 | 重心轻轻前压 / 身体后撤半寸 / 下意识压低身体 | 探查 / 害怕 / 防御 |
| 下肢 | 膝盖有细小稳定调整 / 脚踝轻微发紧 / 蹲姿重心变化 | 原地紧张 / 蹲守 / 屏息 |
| 衣物/头发 | 衣摆轻微摆动 / 发梢被风带动 | 氛围补充，不能替代表演本体 |

## 四、常用情绪模板

### 1. 紧张

- 脸部：
  - 眉头轻微收紧
  - 眼睑绷住
  - 嘴唇压紧
  - 下颌发硬
- 身体：
  - 呼吸带动肩背明显起伏
  - 手指慢慢收紧
  - 重心轻微前压

### 2. 惊恐

- 脸部：
  - 眼睛突然睁大一点
  - 嘴微微张开又立刻压住
  - 面部短暂停住
- 身体：
  - 呼吸一滞
  - 肩膀瞬间绷住
  - 身体下意识后缩或压低

### 3. 怀疑 / 侧耳倾听

- 脸部：
  - 眉峰略抬
  - 眼神固定，像在确认声音来源
  - 嘴部保持克制
- 身体：
  - 呼吸变轻
  - 头部极小幅度前探
  - 身体其他部位尽量稳住

### 4. 压抑克制

- 脸部：
  - 嘴唇压得很紧
  - 下颌绷住
  - 眼神不逃
- 身体：
  - 呼吸被压住
  - 肩背僵住
  - 手掌更用力贴住地面或道具

### 5. 着急

- 脸部：
  - 眼神快速确认
  - 眉头更明显地拧住
  - 嘴部准备说话但没说
- 身体：
  - 呼吸更快
  - 动作频率略快
  - 手部收紧更明显

## 五、不同镜头对表演的写法要求

| 镜头类型 | 表演重点 |
|---------|---------|
| 后侧中景 | 以呼吸、肩背、手部、重心为主，脸只写侧脸能见的信号 |
| 侧后中近景 | 可加入眉、眼、嘴、下颌 |
| 近景/中近景 | 脸部信号优先，身体保留呼吸和手部辅助 |
| 全身动作镜头 | 以姿态、重心、手臂和下肢为主，不要强求细眉眼 |

---

## 六、AI 视频使用提醒

- 如果脸在画面里太小，再怎么写眉眼嘴也不会明显生效。
- 如果身体是蹲姿或趴姿，下半身不能完全不写，否则人物会像只动上半身的贴图。
- “人物不动”和“人物保持原位”不是一回事：
  - 可以保持原位
  - 但必须有呼吸、受力、姿态调整

---

## 七、可直接复用的短句模板

- `侧脸能看出明显紧张，眉头轻微收紧，眼睑绷住，嘴唇压紧，下颌发硬。`
- `呼吸让肩背有清晰可见的起伏，撑地的手指缓慢收紧，重心轻轻前压。`
- `人物保持原位，但不是静止贴图，身体始终处在紧张受力状态里。`
- `听到关键词后，下颌明显收紧一下，鼻翼轻微张开，眼神短暂抬起又压回去。`
- `原本带一点不服，听到关键句后嘴角僵一下，胸口起伏短暂停半拍，随后又重新压住。`
- `群像不是静止摆拍，主说话人之外，其余角色各自只有短促且不同步的微反应。`
