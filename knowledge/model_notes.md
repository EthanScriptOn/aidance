# Model Notes

## Seedance 2.0

Practical defaults:

- Use `9:16` for vertical manga drama.
- Use `5-7s` clips for emotional beats.
- Use `6-8` explicit shots when the scene is a fast human conflict.
- Upload every visible character reference.
- Upload key props if recognition matters.
- Keep unuploaded characters offscreen.

Prompt style:

- Seedance responds well to storyboard-style instructions.
- Write `Shot 1`, `Shot 2`, etc.
- Name shot size and duration.
- Give each shot one action or reaction.
- Avoid giant blocks of prohibitions.

Useful wording:

```text
Generate a 9:16 vertical video, about 6 seconds, 7 fast shots.
Each shot has clear character action, not a slideshow.
```

## What To Avoid

- 6 seconds with only 2-3 shots for a fast emotional beat.
- Long prompts where every shot repeats all blocking facts.
- Abstract words like cinematic, oppressive, tense without visible behavior.
- Letting visible background characters appear without reference images.
- Saying characters are leaving when the story says they are moving toward a task.

## Minimal Lighting Inheritance

For ep01 night exterior, one sentence is usually enough:

```text
Cold blue-white moonlight cuts from upper right; right faces and shoulders have rim light, left sides fall into shadow, and the cave mouth stays pure black.
```
