# ep01 分镜图关键帧提示词

用途：

- 本文件用于先给 `gpt-image` / Image2 生成分镜图
- 只覆盖适合分镜图驱动的高风险 Beat：`beat_04`、`beat_04b`、`beat_08`、`beat_09`、`beat_10`、`beat_13`、`beat_15`

通用规则：

- 9:16 竖屏
- 中国探险悬疑漫画风，硬朗线条，粗粝质感，高质量线稿加色彩渲染
- 1960 到 1970 年代湖南农村盗墓前传气质，无现代物件
- 月光统一来自右上方约 40 度，阴影投向左下
- 主色调深褐、墨绿、黑，冷蓝白月光高光，深红褐只作为异常或代价信息点
- 静态分镜图，不做运动模糊，不做镜头特效字，不做字幕
- Beat04 系列必须继承 `output/ep01/cinematography.md`：低调曝光、右上冷月边缘光、中到大景深、人物和洞口/绳线职责关系可读
- 对 `gpt-image`，角色身份绑定依赖“上传顺序 + 文本显式指代”
- 默认上传顺序：主角色优先第 1 张，主场景优先第 2 张，关键物和武器放后面
- 每条 prompt 都必须先声明“第几张图是谁，负责锁什么，不负责锁什么”，再写画面
- 禁止合影式站姿或角色设定展示感；不要机械写“看镜头/不看镜头”，必须结合本 Beat 的上下文、人物心理和动作边界，写清每个人此刻被什么牵引、应该看向哪里、身体朝向哪里、手在做什么

## Beat 04A · 分工落定

### Frame 04A-01

本帧建议上传顺序：

- 第1张：老烟头
- 第2张：盗洞口
- 第3张：大胡子
- 第4张：老二·独眼二伢子
- 第5张：老三
- 第6张：土耗子
- 第7张：旱烟枪
- 第8张：匣子炮

参考图对应关系：

- 第1张是老烟头，只锁老烟头的脸、体型、衣着和年龄感
- 第2张是盗洞口，只锁土丘顶部、纯黑洞口和周围黄土布局
- 第3张是大胡子，只锁大胡子的身份和外形
- 第4张是老二，只锁老二身份和外形
- 第5张是老三，只锁老三身份和外形
- 第6张是土耗子，只锁绳具形态
- 第7张是旱烟枪，只锁烟枪样式
- 第8张是匣子炮，只锁枪型

visibility_contract：

- 本帧是同侧观察的群像重排建立镜，可见四个已上传人物，但洞内保持纯黑，不出现洞内人物、肢体或脸
- 洞口是垂直向下的纯黑圆口，不画成井台、台阶、斜坡、横向隧道或门洞
- 四人必须按职责分组：前三人朝洞口方向收紧，老三在外围守尾端，不让任何人正对镜头摆拍

frame_continuity_contract：

- previous_frame_state：Beat04 进入分工阶段，四人仍在洞口地面，尚未正式下洞
- start_state：老烟头开始把顺位压向洞口，大胡子和老二靠近下洞队列，老三仍在外围
- end_state：老二带土耗子前端靠近洞口方向，土耗子尾端开始延向老三守位，老三被视觉上排除在下洞队列外
- visible_characters：老烟头、大胡子、老二、老三四人可见，身份必须来自上传参考
- offscreen_characters：无
- visible_object_state：土耗子作为绳线动线可见，旱烟枪在老烟头手里，匣子炮在老二腰侧
- implied_object_state：土耗子前端尚未正式下放，洞内没有可见人物或动作
- next_frame_handoff：04A-02 继续压场点名，尾端职责进一步落到老三手里

reference_bound_visibility：

- 画面中所有人物都必须对应本帧上传参考；不得新增第五个人、陌生人头或无法指认的影子人物
- 老二必须保留独眼/头缠布/腰侧匣子炮特征，不得画成第二个大胡子

单张生图直贴 prompt：

```text

画面抓住“分工正在发生”的瞬间：老烟头站在画面右中偏前、最靠近洞口前缘，身体朝洞口，头微微回向众人，手里唯一一根旱烟枪斜指洞口和下洞顺位；大胡子在老烟头左后半步，身体向洞口压近，眼睛看老烟头手势或洞口；老二在更后一点的左侧偏后，独眼/头缠布清楚，腰边带匣子炮，一手带着土耗子前端，视线看绳线和洞口；老三被分离到洞口外侧右后位，双手准备接住土耗子尾端，眼神在老烟头手势和自己将要接住的绳尾之间。土耗子从老二/洞口方向斜向老三守位延伸，让观众一眼看懂“前三人要下，老三被留下守尾端”。夜景低调曝光，月光从右上约40度斜切，洞口边沿只有冷灰黄窄亮边，洞内纯黑。
```

## Beat 04B · 下洞启动

### Frame 04B-01

本帧建议上传顺序：

- 第1张：老烟头
- 第2张：盗洞口
- 第3张：大胡子
- 第4张：老二·独眼二伢子
- 第5张：老三
- 第6张：土耗子
- 第7张：匣子炮

参考图对应关系：

- 第1张是老烟头，只锁第一个下洞者身份、脸和衣着
- 第2张是盗洞口，只锁垂直洞口、土丘顶面和洞内纯黑
- 第3张是大胡子，只锁第二顺位人物身份
- 第4张是老二，只锁第三顺位人物身份
- 第5张是老三，只锁地面守尾端的人是谁
- 第6张是土耗子，只锁绳具形态
- 第7张是匣子炮，只锁老二腰边武器样式

visibility_contract：

- 本帧是 04B 下洞启动第一帧，可见四个已上传人物；洞内仍然纯黑，不显示洞内底部或洞内人物脸
- 这是 04A-03 之后的动作推进，不能回到分工讨论，也不能让地面只剩老三
- 洞口机制开始可见：老烟头到洞沿准备下，老三继续在外侧守尾端

frame_continuity_contract：

- previous_frame_state：04A-03 已建立老三在地面抓住土耗子尾端，绳线通向洞口/黑暗方向，前端铁钩不可见
- start_state：前三人回到画面并进入洞口执行位，老三仍在外侧守尾端
- end_state：老烟头在洞口边缘蹲低或坐到口沿，准备第一个下；大胡子第二位等待，老二第三位带土耗子和匣子炮，老三仍守尾端
- visible_characters：老烟头、大胡子、老二、老三四人可见
- offscreen_characters：无
- visible_object_state：土耗子绳线连接老三守位与洞口方向；老二腰侧匣子炮可见；老烟头身体到洞沿但尚未完全消失
- implied_object_state：洞内仍纯黑，正式下洞刚启动，不显示洞内纵深人物
- next_frame_handoff：04B-02 推进到老烟头第一个下洞的近景机制

reference_bound_visibility：

- 四个可见人物都必须对应上传参考；老二不得画成大胡子，老三不得进入下洞队列
- 不允许新增陌生人、洞内脸、洞口浮脸或第五个人
