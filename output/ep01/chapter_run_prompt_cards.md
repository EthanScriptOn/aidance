# 章节运行提示词卡 ·《血尸》

本文件按新流程运行：

```text
事实 -> 戏剧 -> 镜头行为链 -> 直贴提示词 -> 复核
```

章节策略：

- 不逐句改编原文。
- 把整章拆成短视频片段。
- 每个片段只承担一个“信息转折”或“人物状态变化”。
- 人物冲突戏默认 6 秒 / 7 镜头。
- 动作、恐怖、机制戏按 5-10 秒处理。

全章统一风格：

```text
9:16 竖屏，中国探险悬疑漫画风，硬朗线条，粗粝质感，写实东方人物比例，1960-1970 年代湖南农村土夫子时代，无现代物品。冷蓝白月光从画面右上方斜切，人物右脸和右肩有冷白边缘光，左脸和身体背光面压入暗部。洞内、林地深处和怪物来向保持大面积纯黑，除非揭示镜头明确需要露出局部。
```
