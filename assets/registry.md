# 资产注册表 (Asset Registry)

> 跨集视觉一致性的核心管理文件。
> **每次新集开始，美术指导必须先查此表再设计。每集结束，必须更新此表。**

---

## 锁定协议

| 状态 | 含义 | 操作规则 |
|-----|-----|---------|
| 🟢 已锁定 | 图片已确认为规范版本 | **禁止重新生成**，所有引用必须使用此图；新集生成变体时，必须上传此图作为参考（图生图） |
| 🟡 有变体 | 主版本已锁定，存在集数相关变体 | 主版本同上；变体图片独立锁定，标注出现集数 |
| ⚪ 待生成 | 提示词已写，图片尚未生成 | 生成后更新状态为🟢 |
| 🔴 已弃用 | 被新版本替代 | 不可再引用，保留文件用于历史参考 |

**图生图一致性原则：**

| 资产类型 | 生成方式 | 说明 |
|---------|---------|-----|
| 角色标准三视图（首次） | 纯文字生图 | 首次设计，无参考图 |
| 角色变体（受伤/换装/状态变化） | 图生图，上传 `char_xxx_main.png` 作参考 | 保证脸型/体型与主版一致 |
| 场景九宫格整图（首次） | 纯文字生图（一次生成全部格子） | 类似角色三视图，模型在同一次生成中维持一致性 |
| 子场景九宫格 | 图生图，上传父场景 `scene_xxx_main.png` 作参考 | 保证子场景与父场景环境一致 |
| 独立道具图 | 纯文字生图 | 道具无历史参考图，首次生成 |
| 跨集已有资产 | 图生图，上传锁定图作参考 | 不得用文字重新生成，会导致外观漂移 |

## 外观冲突处理协议

当新集剧本或 agent 生成的描述与已锁定资产存在差异时，**必须先判断冲突类型，再决定处理方式**。

### 判断树

```
新描述与注册表不一致
        ↓
是否有明确的剧情原因？（换装、受伤、时间流逝、身份变化…）
        ↓
   YES：这是"剧情变体"          NO：这是"描述错误"
        ↓                              ↓
  是永久改变吗？               art_designer 必须阻止
  （此后所有集都是新外观）      回退到注册表锁定版本
        ↓                         不得生成新图
  YES           NO
   ↓              ↓
归档旧版本     新增变体
为 🔴 已弃用   记录出现集数
新图成为      新旧版本并存
新的 🟢
```

### 三种处理方式

**① 剧情变体**（新旧版本并存，各有各的使用范围）
- 主版本保持 🟢，在变体说明表中新增一行
- 记录：变体名、从哪集开始、图片路径、变化内容、触发这个变化的剧情事件

**② 永久外观更新**（从某集起彻底替换，旧版本不再出现）
- 旧规范图状态改为 🔴 已弃用，备注归档原因和集数
- 新图生成后成为新的 🟢 规范版本
- 在"持续性变化记录"列注明：`epXX起永久更新，旧版归档`

**③ 描述错误**（无故事原因的冲突）
- art_designer 必须在 Step 0 标出冲突，暂停设计该资产
- 向用户说明：「[角色名]注册表中为[描述A]，新集描述为[描述B]，无剧情依据，请确认」
- 用户确认是错误 → 使用注册表版本，忽略新描述
- 用户确认是有意修改 → 按②永久外观更新流程处理

## 全系列美术基础锁定（跨所有时代永久有效）

> **本区块描述所有时代共同的美术风格底层框架。不因时代不同而改变。**
> **所有 agent 设计任何时代的任何资产，都必须遵守本区块。**
> **由 `~start` 首次运行时写入并锁定。**

- **绘制风格**：中国探险悬疑漫画风，参考《鬼吹灯》影视美学
- **线条风格**：硬朗线条，质感粗粝，高质量线稿加色彩渲染
- **人物比例**：写实人物比例，东方审美，无西方哥特元素
- **渲染技法**：漫画风格色彩渲染，强调轮廓与光影对比，局部打光，大面积暗部
- **全系列禁止元素**：西方哥特元素、非写实夸张体型

## 全系列摄影风格锁定

> 每集 `~cin` 产出的摄影概念书必须与此基准一致。

- **主光源方向**：月光统一来自右上方约 40°，阴影统一投向左下（全系列锁定）
- **色彩基调**：深褐/墨绿/黑为主调，冷蓝白月光高光，深红褐为唯一强调色（血液/渗出液）
- **阴影压色**：冷蓝-绿压暗；皮肤在月光下呈冷灰白，不保留自然肤色暖调
- **运镜原则**：静止优先；恐怖时刻用静镜等待，不用运镜制造动感；人物运动打破静止
- **景别体系**：叙事→全景/宽景；情绪→近景；母题时刻→极近特写；动作→手持快切
- **灯光三幕弧线**：幕一（高亮/信息丰富）→ 幕二（渐暗/洞口引入纯黑）→ 幕三（只剩轮廓光，大面积黑暗）
- 详细规则见 `output/ep01/cinematography.md`；后续集数摄影指导必须继承以上锁定项

## 生图参数规范（Google AI Studio）

> 每次生图前对照此表，不要使用默认参数。

| 资产类型 | **AI Studio 输出比例**（在界面里选这个值） | 分辨率 | 推理等级 | 生成模式 |
|---------|------------------------------------------|-------|---------|---------|
| 角色标准三视图 | **1:1**（正方形） | 1K | 高 | 纯文字生图 |
| 角色变体 | **1:1**（正方形） | 1K | 高 | 图生图（上传主图作参考） |
| 场景参考图（9格，3×3） | **9:16**（竖屏） | 1K | 高 | 纯文字生图；子场景用图生图上传父场景图 |
| 场景参考图（6格，2×3） | **9:16**（竖屏，近似） | 1K | 高 | 同上 |
| 独立道具图 | **1:1**（正方形） | 1K | 高 | 纯文字生图 |

> **为什么场景图都用 9:16？**
> - **9格（3×3）**：3列×3行，每格 9:16 → 整图 = 3×9 : 3×16 = **27:48 = 9:16**，数学上完全一致
> - **6格（2×3）**：2列×3行，每格 9:16 → 整图 = 18:48 = **3:8**（无对应标准选项，用 9:16 近似；格子会略微拉伸，不影响参考用途）

**模型**：Gemini 3.1 Flash Image（Nano Banana 2）

## 新集启动检查清单

在新集 `~design` 开始前，美术指导必须完成以下检查：

- [ ] 读取此注册表，识别本集出现的所有已有资产
- [ ] 查"时代段 × 集数对照表"，确认本集时代段 ID
- [ ] 从"时代段视觉设定表"提取本集时代约束：服装/材质年代、主色调、光源类型、特定禁止元素
- [ ] 将时代约束作为角色/场景设计的额外约束层（叠加于全系列美术基础之上）
- [ ] 对每个已有资产，确认其规范图片状态（🟢/🟡/⚪）
- [ ] 已有角色 → 不重新设计，不重新生成规范图，只在确有剧情变化时新增变体
- [ ] 已有场景 → 不重新设计，只在时间/天气/季节变化时新增变体，以规范图为参考
- [ ] 新出现的资产 → 按正常 `~design` 流程设计，完成后更新注册表

`~design` 完成后，美术指导必须更新此注册表：
- [ ] 新资产添加到对应表格，状态标为 ⚪ 待生成
- [ ] **时代段列必须填入正确的时代段 ID**（不得留空）
- [ ] 用户完成生图后，通知更新状态为 🟢 已锁定，填入图片路径
